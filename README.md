# Mongolia River Outfitters — website

Plain HTML, CSS and JavaScript. No build step, no dependencies. Open `index.html`, or upload the folder to any web host.

- `css/styles.css` — all styles (colours and fonts are variables at the top)
- `js/main.js` — menu, tabs, filters, gallery lightbox, team modal, forms
- `img/` — photos and logos, cut from the Figma exports
- Fonts (Fraunces + Work Sans) load from Google Fonts, so they need an internet connection.
